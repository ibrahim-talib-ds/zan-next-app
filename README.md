# ZanNext

> Tanzania's modern marketplace — buy, sell, chat, and deliver with confidence.

ZanNext is a full-featured e-commerce mobile app built for the Tanzanian market. It connects buyers and sellers, supports real-time chat, delivery tracking, and secure payments — all in one polished experience.

---

## ✨ Features

### For Buyers
- **Browse** curated products across 50+ categories (fashion, electronics, groceries, beauty, and more)
- **Search & filter** with live results
- **Chat** directly with sellers in real time
- **Wishlist** products to save for later
- **Order tracking** with status updates
- **Multiple delivery addresses** with map-based location picker
- **Reviews & ratings** from verified buyers
- **Push notifications** for orders, messages, and promotions

### For Sellers
- **List products** with multi-image uploads
- **Manage inventory** from a dedicated seller dashboard
- **Track performance** — views, orders, and revenue
- **Reply to buyers** instantly in the in-app chat
- **Order management** with status flow (Pending → On the way → Delivered)

### For Admins
- **Support inbox** — view and reply to all user conversations
- **User management** and role controls
- **Product moderation** and store insights
- **Broadcast messaging** to users
